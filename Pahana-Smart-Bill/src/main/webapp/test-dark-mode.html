🔧 How It Works

The dark mode implementation uses CSS custom properties (variables) to define colors for both light and dark themes. When the toggle is clicked:

  1. The JavaScript adds/removes the data-theme="dark" attribute from the body
  2. CSS variables automatically switch to dark theme values
  3. All elements using these variables instantly update their appearance
  4. The preference is saved to localStorage for persistence

📱 Responsive Design

The toggle button adapts to different page layouts:

  • Header Pages: Toggle appears in the header next to user info
  • Login/Register: Toggle appears as a fixed button in the top-right
  • Other Pages: Fallback positioning in the top-right corner
